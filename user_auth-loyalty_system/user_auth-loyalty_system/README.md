# 🧺 Cloud Laundry – My Branch (User Auth + Customer Dashboard + Loyalty Points)

## 👤 My Responsibility
This branch contains my part of the Cloud Laundry group project:
- ✅ User Authentication (Login, Register, OTP, Forgot Password, Reset Password)
- ✅ Customer Dashboard
- ✅ Loyalty Points System

## 🚀 How to Run

```bash
npm install
npm run dev
```

Then open: http://localhost:3000
